# 버들여울의 하루 (가제) — 텍스트 TRPG 기획서

> 버전 0.1 / 모든 수치는 플레이테스트 전 **초기안**이며 `balance.json`으로 분리해 조정한다.

## 0. 한 줄 요약과 디자인 원칙

**"용사가 지나가는 마을에서, 용사가 아닌 사람으로 한 해 한 해를 살아내는 이야기."**

| 항목 | 내용 |
|---|---|
| 플랫폼 | iOS / Android 네이티브 (React Native + Expo), 오프라인 우선 |
| 화면/조작 | 세로 고정, 한 손(엄지) 조작 |
| 배경 | 일반적인 중세 판타지 (영주·길드·교회·모험가·마물). 마법은 존재하지만 주인공과는 무관 |
| 주인공 | 이름·출신 직업만 있는 평범한 마을 주민. 특별한 재능·유물·혈통·예언 **없음** |
| 1회 플레이 | 약 30분 = **1계절(20일)**. 언제든 중단·재개 가능 |
| 전체 분량 | 3년 × 4계절 = 12회차(약 6시간) = 1캠페인 |

**디자인 원칙**
1. **평범함이 곧 재미다.** 힘의 인플레이션이 아니라 "선택의 폭과 관계의 깊이"가 성장이다.
2. **실패해도 이야기는 계속된다.** 게임오버 대신 빚·상처·소문 같은 *결과*가 남는다.
3. **확률은 숨기지 않는다.** 모든 판정은 성공률을 보여주고, 플레이어는 준비로 확률을 올린다.
4. **30분 안에 한 덩어리가 끝난다.** 계절 결산이 곧 자연스러운 종료점이다.
5. **엄지 하나로 충분하다.** 모든 핵심 행동은 화면 하단 1/3에서 끝난다.

## 1. 핵심 게임 루프

### 1-1. 하루의 흐름 (목표 70~90초)

```
 아침  ─ 소식 카드(날씨·소문·이벤트)          ~15초
  ↓
 오전  ─ 활동 선택 → 판정 → 결과 카드         ~15초
 오후  ─ 활동 선택 → 판정 → 결과 카드         ~15초
 저녁  ─ 활동 선택 → 판정 → 결과 카드         ~15초
  ↓
 밤    ─ 정산(식사·지출·체력 회복) + 일기 한 줄 ~15초
```

- 하루는 **3개의 시간대 슬롯**(오전/오후/저녁)이다. 각 슬롯에서 카드 3~4장 중 1장을 고른다.
- 아침 소식과 일부 슬롯에는 **이벤트 카드**가 끼어들어 선택지가 바뀐다.
- 밤 정산에서 식량 1 소비, 체력·마음 회복, 자동 저장이 이뤄진다.

### 1-2. 계절(1회 플레이) 구성 (목표 28~30분)

| 구간 | 내용 | 시간 |
|---|---|---|
| 시작 | 지난 계절 요약, 이번 계절 목표(세금·행사) 확인 | ~1분 |
| 본편 | 20일 (고정 메인 이벤트 3~4개 + 랜덤 이벤트) | ~24분 |
| 결산 | 계절 축제/세금 납부, 큰 선택 1회, 성과 정리, 다음 계절 예고 | ~4분 |

> 하루 단위 자동 저장. 앱을 닫으면 "이어서 하기"로 그 슬롯에서 복귀한다. 30분은 *목표 길이*이지 제한 시간이 아니다.

### 1-3. 활동 카드 종류

| 종류 | 예시 | 주 효과 |
|---|---|---|
| 일/생계 | 밭일, 땔감 모으기, 대장간 심부름, 주점 설거지 | 돈·식량, 근면/손재주 숙련 |
| 거래 | 장터에 내다 팔기, 행상과 흥정 | 돈, 말솜씨 숙련 |
| 관계 | 이웃 돕기, 대화, 선물, 부탁 들어주기 | 인연·평판 |
| 탐색 | 숲 가장자리 채집, 소문 캐기, 길 살피기 | 재료·정보, 눈썰미 숙련 |
| 준비 | 도구 손질, 레시피 연습, 장부 정리 | 다음 판정 **준비 보너스** |
| 휴식 | 낮잠, 가족과 식사, 교회 기도 | 체력·마음 회복 |

### 1-4. 화면 구성 (세로, 한 손)

```
┌────────────────────────┐
│ 봄 7일째 · 맑음  ⚙      │ ← 상단: 읽기 전용 (탭 불필요)
│ ❤ 7/10 ☁ 8/10 🪙 42 🌾3 │
├────────────────────────┤
│                        │
│  새벽 안개 속에서 …     │ ← 중단: 스토리 텍스트
│  (스크롤, 글자 크기 조절)│    탭하면 다음 문장 / 길게 누르면 로그
│                        │
├────────────────────────┤
│ [ 🌾 밭일     72% ]     │ ← 하단 1/3 = 엄지 영역
│ [ 🗣 장터 흥정 58% ]     │    큰 버튼(최소 56dp), 성공률 표기
│ [ 🔧 도구 손질  준비 ]   │    길게 누르기 = 상세 보정 내역
│ [ 💤 쉬기         ]     │
└────────────────────────┘
```

- 주사위는 **버튼 탭 → 아래에서 위로 스와이프(또는 탭)**로 굴림. 햅틱 피드백(`expo-haptics`).
- 메뉴(인벤토리·인물·일지)는 **하단 탭 바**, 뒤로가기 제스처는 시스템 기본만 사용.
- 가로/왼손·오른손 전환 옵션, 글자 크기, 텍스트 속도, 색약 모드를 제공한다.

## 2. 스탯·자원 시스템과 판정 규칙

### 2-1. 능력치 (4종, 범위 0~4)

| 능력치 | 의미 | 관련 활동 |
|---|---|---|
| **근면** | 몸을 쓰는 끈기 | 농사, 짐 나르기, 벌목, 방어 거들기 |
| **손재주** | 만들고 고치는 솜씨 | 수리, 요리, 약초 가공, 공예 |
| **말솜씨** | 사람을 대하는 힘 | 흥정, 설득, 사과, 중재 |
| **눈썰미** | 알아채는 힘 | 채집, 소문, 함정·거짓말 간파, 길 찾기 |

- 시작값: 출신 직업에 따라 **합계 4점**(예: 농부의 자식 근면2·눈썰미1·손재주1). 5는 존재하지 않는다.
- "4"는 *마을에서 알아주는 일꾼* 수준이다. 영웅급 수치는 없다.

### 2-2. 자원

| 자원 | 범위/단위 | 역할 | 0이 되면 |
|---|---|---|---|
| **체력** | 0~10 | 노동 슬롯마다 소모 | 쓰러짐: 다음 슬롯 소실 + 치료비 10동 또는 빚 |
| **마음** | 0~10 | 사건·갈등·재도전에 소모 | 번아웃: 하루 강제 휴식, 다음 날 판정 −1 |
| **돈** | 동(銅) | 세금·도구·식량·선물 | 부족분은 **빚**으로 전환(이자 붙음) |
| **식량** | 개수 | 매일 밤 1 소비 | 굶음: 체력 회복 0, 마음 −1 |
| **평판** | 3트랙, 각 −5~+10 | **이웃**(마을 공동체) / **상인**(장터·행상) / **관청**(영주·교회) | 트랙별 선택지·가격·사건 변화 |
| **인연** | NPC별 0~3단계 | 도움 보너스, 개인 이야기 해금 | — |
| **빚** | 동 | 계절 말 이자 10%, 엔딩 영향 | 일정액 초과 시 몰락 루트 플래그 |

**기준 경제 (1계절 20일)**
- 일당 수입 평균 6동/노동 슬롯, 하루 평균 노동 슬롯 1.5 → 계절 수입 약 **180동**.
- 지출: 식량 1일 3동(60), 계절 세금 30~80동, 수리·도구·기타 20~40동. → **빠듯하지만 가능**.
- 여유분 약 10~30동이 도구·선물·저축으로 흘러가는 *선택의 여지*다.

**체력/마음 증감 기준**
- 노동 활동 −2 체력, 가벼운 활동 −1, 휴식 +3, 식사 +2, 수면 +4(식량 있을 때 자동).
- 낮음 페널티: 체력 또는 마음 ≤ 3 → 판정 −1.

### 2-3. 판정 규칙: 2d6 합산

```
판정값 = 2d6 + 능력치(0~4) + 준비/도구(0~+2) + 도움(인연 0~+1) − 상태 페널티(0~−2)
판정값 ≥ 난이도 → 성공
```

난이도: **쉬움 5 / 보통 7 / 어려움 9 / 매우 어려움 11**

2d6은 종 모양 분포라 "평범한 사람은 대체로 해내지만 가끔 어긋난다"는 감각을 준다.

| 필요 값 | 5 | 6 | 7 | 8 | 9 | 10 | 11 |
|---|---|---|---|---|---|---|---|
| 성공률 | 83% | 72% | 58% | 42% | 28% | 17% | 8% |

**결과 5단계**

| 단계 | 조건 | 처리 |
|---|---|---|
| 대성공 | 합이 난이도+4 이상, 또는 6·6 | 보상 +50%, 숙련 +1 추가, 소문 가능 |
| 성공 | 난이도 이상 | 기본 보상 |
| 아슬아슬 | 난이도−1 ~ −2 | **성공하되 대가**(체력 −1, 돈 소량, 오해 등) |
| 실패 | 그 이하 | 보상 없음, 가벼운 손실, **경험은 절반 인정** |
| 대실패 | 1·1 | 사건 발생(부상, 도구 파손, 평판 하락 중 하나) — 스토리 훅으로 활용 |

**플레이어 개입 수단 (운 → 계획으로)**
- **준비**: 전 슬롯에서 "준비" 카드를 쓰면 다음 같은 계열 판정 +1(1회성).
- **재도전**: 마음 −2로 같은 판정 다시 굴림. 하루 1회, 더 나쁜 쪽을 택하지 않고 *새 결과를 따른다*.
- **도움 요청**: 인연 2단계 이상 NPC에게 부탁하면 +1 (대가: 나중에 부탁 들어줘야 함).
- **물러서기**: 위험 카드는 "포기" 선택지를 항상 제공한다(손실 최소).

**원칙: Fail Forward.** 모든 실패에는 다음 선택지를 만드는 문장이 붙는다. 사망은 특정 고위험 이벤트에서 *사전 경고 후* 에만 발생한다.

## 3. 평범한 주인공의 성장 방식 (기연 없음)

레벨·스킬트리·장비 인플레이션 대신 **다섯 갈래의 "쌓이는 평범함"**을 쓴다.

### 3-1. 숙련 — 해본 만큼 는다
- 판정마다 해당 능력치 XP: 성공 +1, **실패 +1(깨달음)**, 난이도 9 이상 +2, 스승(NPC)이 곁에 있으면 ×1.5.
- 필요 XP: 0→1 = 8, 1→2 = 20, 2→3 = 40, 3→4 = 70. (한 분야 집중 시 2년 차 말 3, 3년 차 4에 도달하도록 튜닝)
- 능력치는 **절대 급상승하지 않는다.** 대신 올라갈 때마다 새 카드가 열린다(예: 손재주 3 → "수리 의뢰" 카드).

### 3-2. 도구와 터전 — 환경이 사람을 만든다
- 도구(괭이·낫·저울·약절구)는 계열별 +1~2 보너스, **내구도**가 있어 손질 필요.
- 집·밭·창고 개선(지붕 수리, 밭 확장)은 돈·시간을 장기 투자하는 *저축형 성장*이다.

### 3-3. 인연 — 혼자서는 못 하는 일을 한다
- NPC별 4단계: 낯섦 → 아는 사이 → 믿는 사이 → 서로의 일부.
- 단계가 오르면 **도움 보너스(+1), 정보 공유, 부탁/의뢰, 개인 에피소드**가 열린다.
- 성장의 상한을 *사람의 수*가 정한다 — 이 게임의 핵심 메시지.

### 3-4. 노하우 — 지식 카드
- 소문·책·어른의 한마디로 얻는 **수집형 카드**(예: "비 오기 전날 개구리 소리 → 밭일 난이도 −1").
- 한 번 알면 영구 효과, 단 *특정 조건에서만* 작동해 과하게 강해지지 않는다.

### 3-5. 직업 경력 — 신분의 변화
- 견습 → 일꾼 → 숙련공 → 마을의 이름난 사람(장인/상인/농장주/자경단 등) 4단계.
- 승급은 숙련 + 평판 + 특정 사건 완료. 기연이 아닌 **이력서**로 얻는 지위다.

> **성장 상한 규칙**: 어떤 수단으로도 판정 보정 합계는 +7(능력치4 + 준비2 + 도움1)을 넘지 못한다. 가장 어려운 일(난이도 11)도 최선의 준비로 *가능은 하되 쉽지 않다*.

## 4. 스토리 구조와 엔딩 분기

### 4-1. 세계와 톤
- 배경: 변방 영지의 강가 마을 **버들여울**(주민 약 200명). 이웃 도시와 영주, 순회 교회, 상인 행렬.
- 세계적 사건(마왕 군세, 용사 파티, 전쟁)은 **배경 소음**이다. 주인공은 그 여파를 장바구니·세금·징집령으로 체감한다.
- 톤: 따뜻하지만 낭만화하지 않는 생활 서사. 유머와 쓸쓸함이 섞인다.

### 4-2. 3막 구조 (12계절)

| 막 | 기간 | 주제 | 핵심 사건 |
|---|---|---|---|
| **1막 뿌리내리기** | 1년차 봄~겨울 | 생계와 사람 알기 | 봄 세금 칙령 → 여름 늑대/고블린 소문 → 가을 수확제 → 겨울나기 시험 |
| **2막 흔들리는 마을** | 2년차 | 외부 세계의 침투 | 용사 파티가 마을에 머묾(그들을 돕거나 모른 척), 징집령, 가뭄/역병 중 택1, **연말 마을 입장 결정** |
| **3막 각자의 선택** | 3년차 | 지킬 것 고르기 | 마물 무리가 강을 따라 내려옴. 용사는 오지 못함. 평범한 사람들이 마을을 지킬지 떠날지 결정 → **마지막 겨울** |

- 고정 메인 이벤트 약 40개 + 랜덤 이벤트 덱(생활 70% / 인연 15% / 위기 10% / 연대기 5%).
- 출생의 비밀·선택받음·각성은 의도적으로 **금지**한다. 용사 파티가 주인공을 특별하게 보는 순간이 오면, 그것이 *착각*임을 확인하는 장면으로 쓴다.

### 4-3. 선택의 기록: 삶의 가치 4축
모든 선택지에는 가치 태그가 붙고 누적된다.

| 가치 | 지향 |
|---|---|
| **정(情)** | 가족과 가까운 사람 |
| **책임** | 마을과 공동체 |
| **재물** | 안정과 성공 |
| **자유** | 떠남, 호기심, 나의 길 |

### 4-4. 엔딩 (초기 9종)

최종 결정은 12번째 계절 결산 때, **가장 높은 가치 축 × 자원/평판 상태 × 핵심 플래그**로 결정한다.

| # | 엔딩 | 주요 조건 |
|---|---|---|
| 1 | **마을의 기둥** | 책임 최고 · 이웃 평판 8+ · 마지막 겨울에 마을 수호 참여 |
| 2 | **작은 가게의 주인** | 재물 최고 · 상인 평판 7+ · 빚 0 · 자영업 달성 |
| 3 | **오래 가는 식탁** | 정 최고 · 가족/배우자 인연 3단계 · 집 개선 완료 |
| 4 | **길 위의 행상** | 자유 최고 · 행상 인연 3 · 마을에 이별 선택 |
| 5 | **징집병의 귀향/비석** | 징집령에 응함 플래그 · 체력/마음 상태로 귀향 or 사망 분기 |
| 6 | **이름 없는 평안** | 어느 축도 우세하지 않음 — 조용히 늙음 (가장 흔한 엔딩) |
| 7 | **빚의 그늘** | 빚 150+ · 평판 하락 — 마을을 떠나 일꾼으로 전락 *(배드)* |
| 8 | **한 줄의 기록** *(숨김)* | 용사 파티를 세 번 도움 + 평판 균형 — 연대기에 한 줄만 남음 |
| 9 | **마지막 불빛** *(숨김)* | 3막 마지막 겨울 희생 선택 — 마을 사람들의 회상 형태 |

- 각 엔딩 뒤에는 **"10년 후" 에필로그**(마을과 주요 인연의 후일담) + **놓친 이야기 목록**(안 본 분기 힌트)이 나온다.
- 중도 이탈 엔딩 없음. 어느 계절에서든 재시작 대신 **"그 계절부터 다시 살기"**(체크포인트 롤백)를 지원한다.

### 4-5. 하루의 예시

> **봄 7일째 아침.** 비가 그치고 밭이 질척하다. 이웃 마르타가 "물 빠질 때까지 장터에 가면 어때?"라고 한다.
> ① 🌾 밭 정리 (근면 · 보통 · 58%) ② 🗣 장터에 달걀 팔기 (말솜씨 · 보통 · 72%) ③ 🔧 도구 손질 (준비)
> → 장터에 가서 ② 선택. 2d6 = 9 → 성공. 달걀 6개를 팔아 18동. 상인 평판 +1. 저녁 슬롯에 새 카드: "행상 토비가 사라진 짐수레를 찾는다."

## 5. 오래 플레이하게 만드는 장치

### 5-1. 리플레이 구조
- **출신 10종**(농부·나무꾼·주점 일꾼·대장간 견습·약초꾼 자식 등): 시작 능력치/인연/첫 시즌 이벤트가 달라진다.
- **마을 시드**: 매 캠페인 날씨·소문·랜덤 이벤트 덱이 셔플되고, 어떤 이웃에게 위기가 닥치는지 달라진다.
- **마을 연대기(메타)**: 캠페인이 끝나면 그 결과가 마을 역사로 남고, 다음 캠페인 세계에 반영된다(예: 이전 판에서 마을을 지켰다면 방벽 흔적이 보임). **스탯 계승은 없다** — 계승되는 건 *지식·분위기·선택지*뿐이다.

### 5-2. 수집·발견
- 이벤트 카드 도감(150+), 레시피/노하우 도감, NPC 개인사 챕터, 엔딩 컬렉션.
- 엔딩 뒤 "놓친 이야기" 리포트가 *다음 한 판의 이유*가 된다.

### 5-3. 가벼운 루틴 (스트레스 없는)
- **오늘의 마을 소식**: 하루 1회 접속 시 짧은 소식 카드(스토리 조각/레시피 힌트). 스태미나·대기시간 없음.
- **주간 시드 챌린지**: 모두 같은 마을 시드로 한 계절을 살고, "평범함 점수"(균형 있는 삶의 지표)를 비교한다. 전투력 랭킹이 아님.
- 계절 알림("수확철이 왔어요")은 *사용자 선택(opt-in)*.

### 5-4. 집 꾸미기·개인화
- 방 소품(수집품/선물 받은 물건), 일기장 표지, 주인공 초상(실루엣 + 머리·옷 색).

### 5-5. 수익화 (참고)
- **유료 앱 1회 구매 + 챕터형 확장팩** 우선. 광고·가챠·스태미나 결제는 세계관의 "평범한 삶"과 충돌하므로 배제.

### 5-6. 지표 목표
| 지표 | 목표 |
|---|---|
| D1 / D7 / D30 리텐션 | 40% / 18% / 8% |
| 평균 세션 길이 | 25~30분 |
| 1회차 3막 도달률 | 35% |
| 2회차 시작률(엔딩 후 7일) | 45% |

### 6-2. 범위 밖 (명시적 제외)
- 실시간 멀티플레이/PvP, 길드·채팅
- 상시 전투 시스템(위기는 *선택과 판정*으로 처리하는 *저강도 전투 장면*만 허용)
- 가챠, 에너지 시스템, 캐릭터 성능 강화 결제
- 3D/풀 애니메이션 (연출은 정지 일러스트·타이포·사운드로)

### 6-3. 기술 메모 (React Native + Expo)
- **데이터 주도**: 이벤트·NPC·아이템은 JSON(스프레드시트 → 빌드 시 변환 + 스키마 검증). 코드 수정 없이 콘텐츠 추가 가능.
- **결정적 RNG**: 시드 기반 난수(저장/복원·주간 챌린지 필수).
- **저장**: `expo-sqlite` 또는 MMKV, 슬롯 단위 자동 저장 + 클라우드 백업(옵션).
- **연출**: Reanimated + Gesture Handler(스와이프 주사위), `expo-haptics`, `expo-av`, i18n 키 분리.
- **오프라인 우선**: 네트워크는 오늘의 소식·주간 시드에만 선택적으로 사용.

## 7. 열린 이슈 (플레이테스트 후 결정)

1. 계절 20일이 30분에 정확히 맞는지 — 일수(18/20/22)와 하루 슬롯 수(3 vs 2)를 측정 후 확정.
2. 능력치 4종이 충분한지 — 지나치게 단순하면 "도구/노하우" 비중 확대.
3. 재도전(마음 −2)의 가격 — 너무 자주 쓰이면 −3으로 상향.
4. 사망 가능 이벤트의 빈도 — 평범한 삶의 긴장감 vs 학습된 무기력.
5. 엔딩 #6 "이름 없는 평안"을 기본값으로 삼을 때 만족도 설계.
