# 보리울의 30일 — 게임 기획서 (v0.1)

> 모바일(세로·한 손) 싱글플레이 텍스트 TRPG
> 1인 개발 기준 · 1회 플레이 약 30분

---

## 1. 한 줄 소개와 핵심 재미

**한 줄 소개**
> "선택받지 않은 평범한 농부가, 30일 뒤 마을을 덮칠 재앙 앞에서 주사위와 땀만으로 자기 몫의 결말을 만들어 가는 텍스트 TRPG."

**핵심 재미 3가지**

| # | 재미 | 설명 |
|---|------|------|
| 1 | **약자의 긴장감** | 시작 시 늑대 한 마리도 목숨을 건 상대. 성공 확률 35%짜리 주사위를 굴릴지, 물러설지 매 순간 고민한다. |
| 2 | **눈에 보이는 노력의 대가** | 같은 행동을 반복하면 숙련도가 오르고, 판정 확률이 35% → 60% → 80%로 체감되게 오른다. 레벨업이 아니라 "내가 연습해서" 강해진다. |
| 3 | **빠듯한 하루 관리** | 돈·식량·피로·부상을 저글링하며 "오늘 일을 할까, 검을 휘두를까, 숲에 갈까"를 고르는 생활 시뮬레이션의 손맛. |

## 2. 세계관 요약

설정은 **"익숙한 중세 판타지"** 그 자체를 목표로 한다. 플레이어가 설명 없이도 이해할 수 있어야 하며, 고유 설정은 최소화한다.

### 아르덴 왕국
- 늙은 왕이 다스리는 평범한 중세 왕국. 왕도는 멀고, 변방은 영주가 관리한다.
- 마법은 존재하지만 **귀족·학자의 것**. 서민이 접하는 마법은 마을 의원의 치유 주문, 떠돌이 마법사의 물약 정도.
- 몬스터는 숲과 폐허에 산다. 평소엔 기사단이 큰 무리를 정리하지만, 변방까지 손이 닿지 않는다.

### 고향 마을: 보리울
- 인구 150명 남짓의 보리 농사 마을. 영주에게 세금을 낸다.
- 주요 NPC (MVP 기준 6명)

| NPC | 역할 | 게임 기능 |
|-----|------|-----------|
| 하몬 촌장 | 마을의 어른 | 메인 퀘스트 진행, 평판 확인 |
| 브록 | 대장장이 | 장비 구매·수리, 대장일 노동 |
| 레나 | 은퇴한 병사, 경비대장 | 검술·방어 훈련(유료) |
| 마그다 할멈 | 의원 겸 약초상 | 부상 치료, 약초 매매 |
| 토비 | 여관 주인 | 소문(정보), 식사, 잡일 |
| 가족 (어머니와 어린 동생) | 주인공의 집 | 식량 소비, 엔딩 분기 |

### 주변 지역 (4곳)

| 지역 | 거리 | 성격 | 주요 내용 |
|------|------|------|-----------|
| **개암나무 숲** | 가까움 (행동 1회) | 초반 탐험지 | 사냥, 약초 채집, 늑대·멧돼지, 고블린 흔적 |
| **버려진 감시탑** | 보통 (행동 1회 + 피로↑) | 소형 던전 | 도적 은신처, 옛 병사의 장비, 습격의 단서 |
| **회색 늪지** | 보통 | 고위험 고수익 | 희귀 약초, 거대 거머리·늪 고블린, 길을 잃는 위험 |
| **강변도시 로웬** | 멂 (하루 전체) | 영주의 도시 | 큰 시장, 기사단 모집소, 신전(치료), 영주 알현 |

### 메인 위협
숲 너머에서 **고블린 약탈대**가 세력을 키우고 있다. 30일째 밤, 수확이 끝난 보리울을 습격한다. 영주의 기사단은 다른 전선에 묶여 있어 제때 오지 않는다. (플레이어는 처음에 이 사실을 모르고, 소문과 탐험으로 알아낸다.)

## 3. 주인공 시작 설정

### 능력치 (5종)
| 능력치 | 용도 |
|--------|------|
| **근력** | 근접 공격, 무거운 노동, 힘쓰기 |
| **민첩** | 활, 회피, 도주, 은신 |
| **체력** | 최대 HP, 피로 저항, 질병·독 저항 |
| **감각** | 추적, 함정·위험 감지, 약초 식별 |
| **말솜씨** | 흥정, 설득, 정보 얻기, 평판 |

- 보정치 범위: **-1 ~ +5** (시작은 0~+2, 성장 상한 +4, 장비·상황으로 +5)
- 별도의 주사위 굴림 없이 직업으로 고정 → 캐릭터 생성 1분 이내.

### 시작 직업 후보

| 직업 | 근력 | 민첩 | 체력 | 감각 | 말솜씨 | 시작 숙련 | 시작 자원 | 특징 |
|------|:---:|:---:|:---:|:---:|:---:|-----------|-----------|------|
| **농부** | +1 | 0 | **+2** | +1 | 0 | 농사 2, 생존 1 | 은화 10, 식량 6 | 가장 안정적. 일하기 수입 안정, 피로 회복 빠름. 전투는 약함. |
| **대장장이 견습** | **+2** | 0 | +1 | 0 | +1 | 대장일 2, 둔기 1 | 은화 8, 식량 3, **낡은 망치** | 근접 전투 시작이 유리. 장비 수리비 할인. 노동 피로 큼. |
| **사냥꾼** | 0 | **+2** | +1 | **+2** | -1 | 활 2, 추적 1 | 은화 5, 식량 4, **사냥활·화살 10** | 탐험·원거리에 강함. 마을 평판 시작치 낮음(외톨이). |
| **약초꾼** *(확장)* | -1 | +1 | 0 | **+2** | +1 | 약초 2, 흥정 1 | 은화 7, 식량 3, 약초 3 | 부상 자가 치료 가능. 전투 최약. 늪지 탐험 유리. |
| **여관 심부름꾼** *(확장)* | 0 | +1 | 0 | 0 | **+2** | 흥정 2, 정보 1 | 은화 12, 식량 2 | 소문을 빨리 얻음. 평판 성장 빠름. |

> 공통: HP = 8 + 체력×2, 시작 평판 10(사냥꾼 5), 피로 0.
> 모든 직업은 **같은 엔딩에 모두 도달 가능**해야 한다. 직업은 "출발점과 쉬운 길"만 다를 뿐 운명이 아니다.

## 4. 핵심 게임 루프

### 판정 규칙 (모든 시스템의 기반)
```
D20 + 능력치 보정 + 숙련 보너스 + 상황 보정  ≥  난이도(DC)
```
| DC | 의미 | 예시 |
|----|------|------|
| 8 | 쉬움 | 익숙한 밭일, 토끼 사냥 |
| 12 | 보통 | 늑대와 싸움, 상인과 흥정 |
| 16 | 어려움 | 고블린 전사, 절벽 오르기 |
| 20 | 영웅적 | 약탈대장과 정면 대결 |

- **자연 20**: 대성공(추가 보상, 숙련 경험 2배) / **자연 1**: 대실패(부상·손실)
- **유리함/불리함**: D20 두 개 중 높은/낮은 값. 좋은 준비(정보·장비·휴식)는 유리함, 피로·부상·굶주림은 불리함.
- **확률 표시**: 선택지 버튼에 "성공 확률 약 45%"를 표시한다. 텍스트 게임에서 숫자의 투명성 = 전략의 재미.
- 주사위 굴림은 **탭 1회 + 0.8초 애니메이션**. 설정에서 스킵 가능.

### 하루 구조 (하루 ≈ 1분, 30일 ≈ 30분)
```
[아침] 상태 요약 + 랜덤 소문/이벤트 1개 (자동)
   ↓
[오전 행동] 1개 선택
   ↓
[오후 행동] 1개 선택
   ↓
[저녁] 식사(식량 -1/가족 포함 -2) · 피로 정산 · 밤 이벤트 판정 (자동)
   ↓
다음 날 (7일마다 세금 정산)
```

### 행동 목록
| 행동 | 효과 | 비용 |
|------|------|------|
| **일하기** | 직업/잡일로 은화 획득(판정 성공 시 추가 수입), 해당 노동 숙련 경험 | 피로 +2 |
| **훈련** | 혼자(무료, 경험 적음) 또는 레나에게 교습(은화 3, 경험 많음) | 피로 +2~3 |
| **탐험** | 지역 선택 → 이벤트 카드 2~3장 연속 진행 (전투·채집·발견) | 피로 +2, 위험 |
| **휴식** | 피로 -3, HP +2. 하루 두 칸 모두 쉬면 경상 회복 | 시간 |
| **마을 볼일** | 상점·의원·여관·NPC 대화(평판·정보·퀘스트) | 상황별 |
| **로웬 다녀오기** | 하루 전체 소모. 큰 시장·기사단·신전 이용 | 피로 +3 |

**설계 의도**: 하루 행동이 2개뿐이라 **모든 선택에 기회비용**이 생긴다. "오늘 일하면 내일 훈련비를 낼 수 있다" 같은 계획이 자연스럽게 발생.

## 5. '평범한 주민'다움을 살리는 장치

### ① 생계: 돈과 식량
- **식량**: 매일 저녁 본인 1 + 가족 1 소비. 없으면 '굶주림' 누적 → 판정 불리함, 3일 연속 시 HP 감소.
- **세금**: 7일마다 영주 세금 은화 5. 못 내면 평판 하락 + 빚 → 빚이 쌓이면 '몰락' 엔딩 위험.
- **장비 가격이 비싸다**: 녹슨 검 은화 15, 가죽 갑옷 25. 일주일 아껴 모아야 장비 하나. "장비 하나 사는 게 큰 결정"이 되도록.

### ② 부상과 피로
- **피로 (0~10)**: 7 이상 모든 판정 불리함. 10이면 강제로 쓰러짐(다음 날 오전 소실).
- **부상 3단계**

| 단계 | 효과 | 회복 |
|------|------|------|
| 경상 | 관련 판정 -2 | 휴식 1일 또는 약초 |
| 중상 | 탐험·훈련 불가, 판정 -4 | 의원 치료(은화 5) + 3일 |
| 치명상 | 사망 굴림 대상 | 즉시 치료 필요 (신전/물약) |

- 부상은 **텍스트로 구체적으로** 표현 ("왼팔이 욱신거린다. 활시위를 당기기 힘들다.") → 평범한 몸의 한계를 체감.

### ③ 사망 위험
- HP 0 → **사망 굴림**: D20 + 체력 ≥ 10이면 빈사 상태로 구조됨(중상 + 은화 손실 + 평판 변동), 실패 시 **사망 → 게임 오버**.
- **영구 사망(1회차 종료)**. 대신 30분 단위라 재도전 부담이 적다.
- 위험한 선택지에는 미리 해골 아이콘으로 경고. "도망칠 수 있는" 선택지를 거의 항상 제공 → 죽음은 무모함의 결과이지 함정이 아니어야 한다.

### ④ 평판 (0~100)
- 마을 사람들의 신뢰. 일 돕기, 약속 지키기, 몬스터 퇴치로 상승 / 세금 체납, 도둑질, 약속 어기기로 하락.
- 평판 효과: 상점 가격, 외상 가능 여부, 훈련 교습 수락, **최종 결전 시 함께 싸워줄 민병대 인원**.
- 평범한 사람의 힘은 혼자가 아니라 **"이웃이 믿어주는 것"**에서 나온다는 테마의 핵심 수치.

## 6. 성장 시스템: 레벨 없는 숙련도 성장

### 숙련도 (Skill) — 쓰면 는다
| 분류 | 숙련 항목 (MVP 8종) |
|------|---------------------|
| 전투 | 검술, 둔기, 활, 방어 |
| 생활 | 농사, 대장일 |
| 야외 | 추적, 약초 |
| *(확장)* | 흥정, 은신, 응급처치, 지휘 |

- **등급 0~5**: 무경험(0) → 초보(+1) → 익숙(+2) → 숙련(+3) → 전문(+4) → 달인(+5)
- 해당 숙련을 쓰는 판정을 할 때마다 경험치 획득:
  - 성공: +1 / **실패: +2** ("실패에서 더 배운다") / 대성공: +3
  - 교습 훈련: +3 (돈과 시간을 쓴 대가)
- 다음 등급 필요치: 3 → 6 → 10 → 15 → 21 (누적이 아닌 등급별)
- 30일 동안 집중하면 한 분야 **숙련~전문(3~4)**, 넓게 하면 여러 분야 **익숙(2)** 수준. 달인은 1회차에서 거의 불가 → "평범한 사람의 30일"에 맞는 현실감.

### 능력치 — 몸이 단련된다
- 능력치는 숙련 사용으로 **간접 성장**. 근력 관련 행동(대장일, 검술, 둔기)을 누적 15회 하면 근력 +1 판정(D20 + 현재 근력 ≤ 15 이면 상승. 높을수록 오르기 어려움).
- 30일 동안 능력치 1~2회 상승이 표준.

### 경험 — 사건이 사람을 바꾼다 ('흔적' 시스템)
특정 경험을 하면 작은 영구 효과(특성)를 얻는다. 레벨업 보상 대신 **이야기의 흔적**.

| 흔적 | 획득 조건 | 효과 |
|------|-----------|------|
| 늑대 사냥꾼 | 늑대 3마리 처치 | 짐승 상대 판정 +1 |
| 죽다 살아난 자 | 사망 굴림 성공 | 공포 판정 유리함 |
| 굳은살 | 일하기 15회 | 노동 피로 -1 |
| 동네 일꾼 | 마을 부탁 5회 해결 (`favors_done` 5) | 말솜씨 판정 +1 |
| 상처 입은 다리 | 중상 방치 | 민첩 판정 -1 (영구 페널티도 존재) |

> 1회차에 3~5개 정도 획득. 엔딩 화면에 "당신이 남긴 흔적"으로 표시 → 플레이 기록의 요약 역할.

## 7. 메인 목표와 엔딩

### 메인 흐름 (30일, 3막)
| 구간 | 내용 |
|------|------|
| **1막 (1~10일)** 일상 | 생계 안정, 기초 훈련. 숲에서 이상한 흔적, 사라진 양. |
| **2막 (11~20일)** 징후 | 감시탑에서 고블린 정찰병 발견. 촌장에게 보고 → 영주에게 지원 요청(실패). 플레이어의 대응 방향 선택 시작. |
| **3막 (21~30일)** 준비 | 마을 방어 준비(목책, 민병대 훈련, 무기 조달) 또는 피난 준비 또는 개인적 길. **30일째 밤 습격.** |

> 단서를 못 찾아도 습격은 온다. 준비 정도에 따라 결과가 달라진다.

### 엔딩 (MVP 5종 + 사망)
| 엔딩 | 조건(요약) | 톤 |
|------|-----------|----|
| **마을의 방패** | 습격 방어 성공 (전투 숙련 + 평판 60↑ + 방어 준비) | 이름 없는 영웅. 노래로 남지 않지만 마을은 기억한다. |
| **이웃과 함께 떠나다** | 피난 계획 주도 + 평판 40↑ | 마을은 잃었지만 사람은 지켰다. |
| **로웬의 창병** | 로웬 기사단 모집 시험 통과(전투 숙련 3+) 후 입대 선택 | 기사는 못 되지만 병사의 길을 걷는다. 마을의 운명은 별도 서술. |
| **용사 일행** | 9일차에 지나간 용사 일행이 19일차 이후 돌아올 때 시험 통과(무기 숙련 3+, 9일차에 일행을 도왔으면 2+) → 26일차에 따라나섬 | 노래 속 주인공은 용사지만, 불침번을 선 것은 평범한 마을 사람. 혈통·예언 없이 일행의 한 사람으로 떠난다. |
| **살아남은 자** | 특별한 준비 없이 습격에서 생존 | 쓴맛 나는 평범한 결말. 가장 흔한 엔딩. |
| **빚진 자** | 빚이 한도 초과 | 영지 노역에 끌려감. 습격 이전 종료 가능. |
| **사망** (변형 다수) | 사망 굴림 실패 | 사망 장소·원인별 짧은 묘비문. 수집 요소. |

- 엔딩 판정: **플래그 + 수치 + 최종 결전 주사위**. 준비를 잘해도 마지막 주사위가 결과를 한 단계 흔들 수 있다(예: 방어 성공이지만 큰 희생).
- 엔딩 후 **기록 화면**: 직업, 생존 일수, 흔적, 최고 숙련, 가장 위험했던 순간.

### 확장 엔딩 아이디어
- **대장간을 잇다** (대장일 전문 + 브록의 신뢰), **떠돌이 사냥꾼**, **상인의 길**(은화 200 축적), **약탈대장과의 협상**(말솜씨 루트).

## 8. 출시 범위: MVP vs 확장

### 1차 출시 (MVP) — 목표 개발 기간 4~6개월(1인)
| 항목 | 범위 |
|------|------|
| 직업 | 3종 (농부, 대장장이 견습, 사냥꾼) |
| 지역 | 마을 + 숲 + 감시탑 (**3곳**) — 로웬은 "모집관이 마을에 방문"하는 이벤트로 대체 |
| 숙련 | 8종 / 능력치 5종 |
| 이벤트 | 아침 소문 30개, 탐험 카드 60개(지역당 30), 메인 스토리 이벤트 15개, NPC 대화 이벤트 20개 → **약 125개** |
| 몬스터 | 6종 (늑대, 멧돼지, 도적, 고블린 정찰병, 고블린 전사, 약탈대장) |
| 장비 | 무기 6, 방어구 3, 소모품 5 |
| 엔딩 | 5종 + 사망 변형 5종 |
| 시스템 | D20 판정, 하루 2행동, 생계/피로/부상/평판, 숙련 성장, 흔적 8종 |
| 저장 | 자동 저장 1슬롯 (매일 아침) |
| 연출 | 텍스트 + 지역별 일러스트 4장 + 아이콘, 효과음 소수, BGM 2곡 |
| 수익 | 유료 앱(저가) 또는 무료 + 광고 제거 1회 결제 (단순하게) |

**MVP UI 원칙 (세로 한 손)**
- 화면 상단 15%: 상태 바 (일차 / HP / 피로 / 은화 / 식량 / 평판)
- 중앙 50%: 이야기 텍스트 (스크롤 최소화, 한 장면 4~6줄)
- 하단 35%: **선택지 버튼 최대 4개** (엄지 영역), 성공 확률·비용 아이콘 표기
- 상태 상세/인벤토리는 상태 바를 탭하면 바텀시트로 표시

**구현 팁 (1인 개발)**
- 이벤트·몬스터·아이템을 **JSON/스프레드시트 데이터**로 분리 → 코드 수정 없이 콘텐츠 추가.
- 이벤트 데이터 예시:
  ```json
  {
    "id": "forest_wolf_01",
    "region": "forest",
    "text": "덤불 사이로 누런 눈이 번뜩인다. 늑대다.",
    "choices": [
      { "label": "활을 쏜다", "check": { "stat": "agi", "skill": "bow", "dc": 12 },
        "success": "wolf_hit", "fail": "wolf_charge" },
      { "label": "천천히 물러난다", "check": { "stat": "agi", "dc": 8 },
        "success": "escape", "fail": "wolf_charge" }
    ]
  }
  ```
- 엔진: Unity(+Ink 같은 내러티브 툴) 또는 Flutter/Godot 등 익숙한 것. 텍스트 중심이라 어느 쪽이든 충분.

### 이후 확장 (업데이트 단위)
| 단계 | 내용 |
|------|------|
| **확장 1: 도시와 사람** | 로웬 도시 정식 추가, 약초꾼·여관 심부름꾼 직업, 흥정/은신 숙련, 동료 NPC 1~2명(함께 탐험) |
| **확장 2: 늪과 비밀** | 회색 늪지, 늪 몬스터, 약탈대장 협상 루트, 확장 엔딩 4종 |
| **확장 3: 긴 이야기** | 60일 "긴 모드", 계절(가을→겨울) 변화, 세력별 평판(마을/영주/상인) |
| **편의/메타** | 엔딩·흔적·사망 도감, 플레이 기록 공유 이미지, 다중 저장 슬롯 |

> **확장에서도 지킬 원칙**: 주인공에게 숨겨진 혈통·전설의 검·예언은 절대 추가하지 않는다. 메타 요소(도감 등)도 다음 회차를 **강하게 만들지 않는다** — 플레이어의 "지식"만 다음 판으로 이어진다.

## 부록: 1회차 플레이 예시 (사냥꾼)
1. 1일차: 숲에서 토끼 사냥(활 판정 성공) → 식량 +2. 오후 여관에서 사냥감 판매.
2. 6일차: 늑대에게 물려 경상. 하루 휴식. 세금 내고 나니 은화 2.
3. 12일차: 감시탑에서 고블린 정찰병 발견 → 촌장에게 보고, 평판 +10.
4. 20일차: 활 숙련 3 달성, '늑대 사냥꾼' 흔적 획득. 레나에게 마을 청년 궁수 훈련 제안.
5. 30일차 밤: 지붕 위 궁수대 지휘, 최종 판정 성공 → **엔딩 「마을의 방패」**.
